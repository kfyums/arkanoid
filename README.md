# arkanoid
Арканоид на C++ и SFML.
## Реализовано
- мяч
- каретка
- блоки
- столкновения
- hp блоков
- неразрушаемые блоки
- ускоряющие блоки
- бонусы
- липкий шарик
- одноразовое дно
- изменение размера каретки
## Платформа
Windows
## Библиотека
SFML 2.6.2
## Как запустить
### Visual Studio
1. Установить SFML
2. Создать Empty Project
3. Добавить все .cpp и .h файлы
4. Подключить include и lib SFML
5. Запустить проект
